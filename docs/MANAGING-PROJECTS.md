# Managing your portfolio — a quick guide

Sign in at **yourdomain.com/admin**. Nothing you do in the dashboard requires editing code.

## The Projects screen

- **Published**: live on the website, in the order shown.
- **Drafts**: saved but hidden from visitors.
- **Archive**: removed from the site, and can be restored at any time.

On each row:
- **☆ Feature / ★ Featured** adds or removes the project from the homepage "Featured Work" section, which shows up to four.
- **↑ / ↓** changes the display order.
- **Edit**, **Preview ↗** (shows the project exactly as visitors would see it, drafts included) and **View live ↗**.

## Add a new project

1. Click **+ New project**.
2. **Basics**: enter a title. The page address fills in automatically. Choose a category and the video shape (landscape, vertical or square), and write a one- or two-sentence summary.
3. **Video**: choose one of these:
   - **Upload a file**: an MP4 is best. A progress bar shows the upload.
   - **YouTube / Vimeo / video link**: paste the link. The dashboard confirms when it recognises it.
   - **No video**.
4. **Hover preview clip** (optional): a short silent clip that plays when someone hovers over the card. If you skip it, the main video is used.
5. **Thumbnail**: either upload an image, pick one from the library, or pause the uploaded video on a good frame and click **Use this frame as the thumbnail**. Add a short description of the image (alt text).
6. **Case-study details** (optional): client, year, our role, the project story, deliverables and gallery images. Only add details you have confirmed and have permission to share.
7. Click **Save draft**. Use **Preview this project ↗** to check it.
8. When you're happy, click **Publish**. It appears on the site immediately.

## Edit a project

Open it, make changes and click **Save changes** (published projects) or **Save draft**. The bar at the bottom tells you if there are unsaved changes. Changes to a published project go live as soon as you save.

## Unpublish, archive, restore

- **Unpublish** turns a live project back into a draft (hidden from the site).
- **Archive project** removes it from the site and moves it to the Archive tab.
- In the Archive, **Restore to drafts** brings it back. **Delete permanently** is only available for archived projects and asks you to type the title to confirm.

## Categories

The Our Work filters only show categories that contain at least one published project. When you publish your first website or Shopify project, its category filter appears automatically.

## Enquiries

**Enquiries** lists every contact-form submission. Unread ones are shown in bold and counted in the sidebar. Open one to see all the details, then use **Reply by email**. The "Notification" column shows whether an email alert was actually sent.
